# 機能要件一覧

| id | functionName | description | relatedRequirement | priority |
| --- | --- | --- | --- | --- |
| FR-001 | 設定画面表示機能 | ブラウザ拡張機能のオプション画面として、設定用UIをブラウザ上に描画する機能。オリジナルリポジトリとカスタムリポジトリの選択肢、およびエディション（Lite/Standard/Full）の選択フィールドを提供する。 | BR-001 | 高 |
| FR-002 | リポジトリ設定登録機能 | 「オリジナル(tatesuke)」または「その他(カスタム入力)」を選択・登録できる機能。その他を選択した場合は任意のGitHubリポジトリURLの入力を可能とし、入力されたURL形式の簡易的なバリデーションをクライアントサイドで実行する。※要確認（詳細なバリデーションルールは業務ルール未定義のため暫定定義） | BR-002 | 高 |
| FR-003 | エディション選択機能 | 選択されたリポジトリ情報（オリジナルまたはその他）に応じて、エクスポート先となる「かんたんMarkdown」の適切なエディションURL（Lite / Standard / Full）を動的に生成・提示し、ユーザーに1つ選択させる機能。 | BR-003 | 高 |
| FR-004 | 設定情報永続化機能 | 設定画面でユーザーが入力・選択した情報をブラウザのローカルストレージ（Chrome.storage等 ※要確認）に対して保存（Create/Update）および読み込み（Read）を行う機能。 | BR-004 | 高 |
| FR-005 | カスタムリポジトリ接続検証機能 | ※要確認（技術要件未定義）。ユーザーが「その他」で登録したカスタムリポジトリのGitHub Pages等のURLに対してバックグラウンドで非同期通信（HTTP HEAD/GET等）を行い、実際にホスティングされアクセス可能か検証する機能。接続不可時の警告表示を行う。 | BR-005 | 中 |
| FR-006 | GitHub Markdownプレビューページ検知機能 | ブラウザのコンテンツスクリプトを用い、ユーザーがアクセスしているGitHub上のURLおよびDOM構造をリアルタイムに監視し、Markdownプレビュー画面（拡張子が.mdのファイルの閲覧画面）であることを自動検知する機能。 | BR-006 | 高 |
| FR-007 | エクスポートボタンインジェクション機能 | 検知したGitHubのMarkdownプレビュー画面上のDOM要素（RawやBlameボタンが配置されているアクションバー等）を解析し、隣接する形で「かんたんMarkdownへエクスポート」を行うボタンを動的に配置・挿入する画面制御機能。 | BR-007 | 高 |
| FR-008 | エクスポート開始制御機能 | 動的配置したエクスポートボタンのクリックイベントをハンドリングし、画面上のMarkdownテキストのパースおよび関連画像情報のフェッチ処理等の非同期シーケンスを起動する機能。 | BR-008 | 高 |
| FR-009 | 認証セッション維持機能 | ※要確認（技術制約未定義）。プライベートリポジトリ内の画像データ取得等において、ユーザーが現在GitHubにログインしているブラウザセッション（Cookie等の認証情報）をバックグラウンド処理にシームレスに引き継ぐセッション制御機能。 | BR-009 | 中 |
| FR-010 | Markdownソーステキスト抽出機能 | GitHubのMarkdown表示画面内のDOM要素（またはGitHub API/Raw取得等 ※要確認）から、表示対象ドキュメントの生Markdownテキスト（プレーンテキスト）を抽出・取得する機能。 | BR-010 | 高 |
| FR-011 | Markdownテキスト構文解析機能 | 抽出したMarkdownテキストをパースし、見出し構造やコードブロックなどの各要素に分類すると共に、埋め込まれている画像要素を識別するテキスト解析機能。 | BR-011 | 高 |
| FR-012 | 画像URL抽出・リスト化機能 | 構文解析を通じてMarkdownドキュメント内の画像リンク（Markdown標準の画像記法およびHTMLのimgタグ形式）から画像ソースURL（相対パスおよび絶対パス）を全て抽出し、ダウンロード対象画像リストを動的に生成する機能。 | BR-012 | 高 |
| FR-013 | 画像タグ置換機能 | ※要確認（ドメイン知識未定義）。パースしたMarkdown本文内の画像タグ記述（![]()形式など）を、かんたんMarkdown仕様の添付画像差し込み用独自タグ（Insert Tag形式：例「[かんたんMarkdown添付ファイル:画像名]」など ※詳細仕様は要確認）に一括置換する機能。 | BR-013 | 高 |
| FR-014 | 変換データ構造化機能 | タグ置換を完了したMarkdown本文と、画像制御プロセスから渡されるエンコード済みの添付画像データを「かんたんMarkdown」のデータ構造（または指定エディションに適合する出力用バッファ）に構造化・マージする機能。 | BR-014 | 高 |
| FR-015 | 画像データダウンロード機能 | 抽出された画像URLリストに基づき、各画像をGitHubサーバーから非同期でフェッチし、バイナリデータ（Blobデータ）として一時的にバックグラウンド処理内に取り込む非同期通信機能。 | BR-015 | 高 |
| FR-016 | プライベートリポジトリ認証フェッチ機能 | ※要確認（技術制約未定義）。プライベートリポジトリの画像URLに対して、ブラウザに保存されている認証用クレデンシャル情報を自動的にHTTPリクエストヘッダー等に付与して通信を成功させるセキュアフェッチ機能。 | BR-016 | 高 |
| FR-017 | 画像データBase64エンコード機能 | ※要確認（技術制約・ドメイン知識未定義）。フェッチした画像Blobデータを「かんたんMarkdown」の添付ファイル定義に適合するBase64文字列（Data URL形式）にエンコード変換する機能。※ファイルサイズ上限による例外制限処理を含む。 | BR-017 | 中 |
| FR-018 | Insert Tag紐付け生成機能 | ※要確認（ドメイン知識未定義）。エンコードされた各画像データに対して、一意の識別ID（ファイル名等）を付与し、Markdown本文内に置換・挿入された「Insert Tag」と一対一で対応する添付ファイルオブジェクトを生成する機能。 | BR-018 | 高 |
| FR-019 | エクスポート一括処理制御機能 | Markdownの抽出、構文解析、全画像データのフェッチとBase64変換、およびタグ置換処理の一連の流れをバックグラウンドでバッチ（パイプライン）的に一括実行・制御するトランザクション管理機能。 | BR-019 | 高 |
| FR-020 | 成果物パッケージング機能 | ※要確認（技術要件未定義）。設定画面で指定された「かんたんMarkdown」のエディション（Lite/Standard/Full）のHTMLテンプレートに対して、変換後のMarkdown本文および添付ファイルデータを埋め込み、単一のHTML（またはZIPパッケージ ※要確認）としてダウンロード用ファイルを構成・生成する機能。 | BR-020 | 高 |
| FR-021 | ファイルダウンロード出力機能 | ※要確認（ビジネスルール未定義）。生成された成果物ファイルを、ブラウザのダウンロードAPIを利用してローカル環境に保存する機能。保存時のデフォルトファイル名（例：「[リポジトリ名]_[元ファイル名].html」）を自動算出・付与する命名制御機能を含む。 | BR-021 | 高 |
| FR-022 | エラーハンドリング・ダイアログ表示機能 | ※要確認（業務ルール・技術制約未定義）。画像フェッチのタイムアウト、パース失敗、容量超過、未ログイン（プライベートリポジトリ等）によるエラーを検知し、ユーザーにエラー理由を示すモーダルダイアログまたは通知をGitHub画面上に表示する機能。 | BR-022 | 中 |
