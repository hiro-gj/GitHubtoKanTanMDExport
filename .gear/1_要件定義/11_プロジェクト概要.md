## 2. 目的・利用者・成果物
GitHub上のMarkdownを、かんたんMarkdownのテンプレートHTMLと取得可能な画像・添付ファイルを含む1つのHTMLに変換し、文書の閲覧・持ち運びを支援するChrome拡張機能。
利用者はGitHubのMarkdown閲覧者、カスタムテンプレート管理者、拡張機能のリリース担当者。
拡張機能自身はMarkdownをHTMLにレンダリングせず、Markdown本文をテンプレートのエディタに格納する。表示機能は取得したテンプレートに依存する。

## 3. 対象範囲
| 対象 | 提供する処理 |
| --- | --- |
| GitHub画面 | 小文字 `.md` で終わるpathnameを検知、ボタン挿入、エディション選択 |
| 変換 | Raw本文、テンプレート、画像・DOM由来添付の取得、成功した参照のattach:化 |
| 出力 | 本文・添付をテンプレートへ挿入しBlobによるHTMLダウンロード |
| 設定 | 配信元区分、カスタムURL、既定エディションをローカル保存、HEAD接続確認 |
| 配布 | v*タグでZIPとGitHub Releaseを生成 |

対象外: 専用APIサーバー、DB、独自ログイン、PATの登録、変換履歴、複数文書一括変換、完全なMarkdown構文解析、テンプレートの編集・安全性検証。

## 4. 前提・保証しない事項
- Manifest V3対応Chromeが必要。最低バージョンと他ブラウザは未定義。
- 変換時はネットワークが必要。出力後の完全オフライン動作は、添付の取得成否とテンプレートの外部依存に左右される。
- プライベート文書はRawリンクやセッション・ホスト権限・署名URLの状態に依存する。全環境での取得成功は保証しない。fetchにcredentialsの明示指定はない。
- 外部テンプレートは毎回取得し、バージョン固定・ハッシュ検証を行わない。

## 5. 既知の制約・不一致（課題ID）
| ID | 現状・影響 | 根拠 |
| --- | --- | --- |
| LIM-01 | Standard接続テストはktm-std.htm、出力時はktm-std.html。接続成功と出力可否が一致しない場合がある | options.js editionTemplates / background.js editionTemplates |
| LIM-02 | 画像キーは英数字・ドット・ハイフン以外を_に置換。同名・日本語名は衝突し得る。後から代入する添付が上書きする | background.js handleExport |
| LIM-03 | 正規表現ベースの抽出は参照形式画像・括弧を含むURL・コードブロックを正しく区別しない | background.js imgPattern / htmlImgPattern |
| LIM-04 | テンプレートのeditorは完全一致文字列、fileListは特定正規表現で置換。不一致でも失敗にせず未挿入のHTMLを保存する | content.js downloadGeneratedFile |
| LIM-05 | 独自タイムアウト、再試行、同時取得数・容量上限、進捗率、処理中キャンセルなし | background.js / content.js |
| LIM-06 | URL分割はbranchを1区間として扱う。スラッシュ入りref・特殊URLのrepoInfoと出力名は要検証 | content.js handleExportClick |
| LIM-07 | 必須ホスト権限に全GitHub Pages・githubusercontentサブドメインを含む。通常Pagesでは任意権限の要求が発生しない場合がある | manifest.json / options.js |
| LIM-08 | 単一添付失敗はwarnのみで成功応答。ユーザーへの欠落一覧なし | background.js handleExport |
| LIM-09 | モーダル表示中は元ボタンを無効化しない。再表示時に旧Escapeリスナーを解除しない経路がある。フォーカストラップ・ARIA dialogなし | content.js showEditionSelector |
| LIM-10 | 保存エラー・破損設定の包括的検証なし。不正repo_typeの再読込でnull.checkedになる可能性 | options.js DOMContentLoaded |
| LIM-11 | 本文のString.replace置換文字列に$&等を含むと展開され、元Markdownが変化し得る | content.js downloadGeneratedFile |
