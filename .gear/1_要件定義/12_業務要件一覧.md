# 業務要件一覧

現状の業務を実装から整理した要件。優先度は本仕様書での確認優先度であり、合意済みSLAではない。

| ID | 業務要件・受入条件 | 優先度 | 機能 |
| --- | --- | --- | --- |
| BR-001 | GitHubの対象Markdown閲覧画面で操作を開始し、出力エディションをその都度選択・キャンセルできる | 高 | FR-001, FR-006 |
| BR-002 | Raw本文、テンプレート、取得可能な画像・添付を統合したHTMLを保存できる。部分取得失敗は現状継続する | 高 | FR-002, FR-007, FR-008, FR-009, FR-010, FR-011 |
| BR-003 | テンプレート配信元を公式または形式に適合するカスタムGitHubリポジトリに切り替え、端末内で保持できる | 中 | FR-003 |
| BR-004 | 既定エディションLite/Standard/Fullを保持し、実行時の一時選択を優先できる | 中 | FR-003, FR-006 |
| BR-005 | カスタムURLを検証し、選択エディションのテンプレートにHEAD疎通確認できる。疎通確認は保存必須条件ではない | 中 | FR-004 |
| BR-006 | リリース担当者がv*タグを起点にインストール可能なZIPを配布できる | 中 | FR-005 |

## 業務上の注意
- BR-002は「すべての添付が必ず埋め込まれる」を意味しない（LIM-08）。共有前に出力確認が必要。
- BR-005のStandardはLIM-01がある。HEAD成功は本文・添付の取得成功やテンプレート構造互換性を保証しない。
- 機密文書の生成HTMLも機密データとして扱う。元リポジトリのアクセス制御はローカルHTMLには継承されない。

根拠: content.js handleExportClick / background.js handleExport / options.js / release-extension.yml。
