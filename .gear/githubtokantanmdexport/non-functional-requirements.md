# 非機能要件一覧

| id | category | requirement | targetValue | priority |
| --- | --- | --- | --- | --- |
| NFR-001 | 性能 | エクスポート処理および単一HTML生成の処理速度 | Raw Markdownおよび画像・添付ファイルのフェッチ・Base64変換・HTML合成処理を5秒以内に完了すること（ネットワーク遅延を除く） | 高 |
| NFR-002 | 性能 | GitHub画面監視時のブラウザ負荷抑制 | MutationObserverによるDOM監視において500msのデバウンス制御を行い、ブラウザの描画遅延やCPU高負荷を発生させないこと | 中 |
| NFR-003 | 可用性 | GitHub SPA遷移およびDOM動的変化への対応 | ページ遷移やReactベースのコンポーネント再描画を検知し、99.9%以上の確率でボタン重複なく確実にエクスポートボタンを自動再挿入すること | 高 |
| NFR-004 | セキュリティ | Manifest V3規約準拠および権限の最小化 | Chrome Extension Manifest V3仕様に完全準拠し、オプション機能の外部接続にはオプショナル権限リクエスト（chrome.permissions）を使用すること | 高 |
| NFR-005 | セキュリティ | インジェクション攻撃防止（XSS対策） | HTMLテンプレート内へのMarkdownテキストおよび添付ファイル情報の埋め込み時、特殊文字の確実なエスケープ処理を実施すること | 高 |
| NFR-006 | 運用 | CI/CDパイプラインによる自動パッケージングおよびリリース | バージョンタグプッシュ時にGitHub Actionsが正常完了し、manifest.jsonのバージョン補正とリリースZIPの作成が自動的に行われること | 中 |
| NFR-007 | 拡張性 | テンプレートリポジトリおよびエディションの柔軟な切り替え構造 | 公式リポジトリ/カスタムURLおよび複数エディション（Lite/Standard/Full）の拡張に対応できる柔軟なURL解決・データ設定保持構造を有すること | 中 |
