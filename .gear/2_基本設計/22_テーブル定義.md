# テーブル定義

## 1. 物理DBは存在しない
RDBテーブル・SQL・主キーid・外部キーはない。本書は設定キーと処理中のJavaScriptオブジェクトを定義する。文字列長・DB型の制約を仮定しない。

## 2. 永続設定（API-003）
保存先はchrome.storage.local。sync/localStorageではない。未保存キーは存在しない。

| キー | 型・通常値 | 未設定時 | 更新・利用箇所 |
| --- | --- | --- | --- |
| repo_type | string: original / custom | Workerはoriginal、OptionsはHTML初期original | Options保存、Worker配信元決定 |
| custom_repo_url | string: GitHub repo URL、または空文字 | Workerは空文字 | Optionsでtrim後保存。custom時のみ形式検証 |
| edition | string: lite / standard / full | Worker/Content Scriptはlite、OptionsはHTML初期lite | Options保存、モーダル既定値、Worker fallback |

読み書きは3キーをget/setするだけ。updated_at、設定ID、接続結果、変換履歴、本文、添付の永続保存はない。保存失敗のlastError確認なし。
Optionsでoriginalへ変更したときはURLを消す。ただし読込時はtoggle後に保存済みURLを反映するため、originalでも無効欄に旧URLが表示され得る。

## 3. exportMarkdown要求の一時データ（API-001）
| フィールド | 型 | 内容 |
| --- | --- | --- |
| markdownFetchUrl | string | Rawボタンのリンク優先、なければURL変換結果 |
| rawUrl | string | 現在URLをraw.githubusercontent.com形式へ変換した相対画像解決基準 |
| repoInfo | object | owner/repo/branch: string。pathnameの1/2/4番目区間 |
| fileName | string | pathnameの5番目以降を/結合。サブディレクトリを含む |
| edition | string | モーダルの一時選択。保存されない |
| attachmentsMetadata | array | {uuid: string, url: string, filename: string}の配列 |

## 4. 内部マップ（BP-005 / BP-006）
| 構造 | キー | 値 |
| --- | --- | --- |
| metadataByUuid | DOM抽出UUID（大文字小文字を保持） | uuid, url, filename, priority（戻す際priority除外） |
| imageMap | 元の画像src全文 | key, originalSrc, dataUrl（初期null）, success（初期false） |
| attachmentMap | UUID小文字 | key, filename, uuid, url, dataUrl, success |
| attachments | サニタイズ済み添付名 | data:MIME;base64,... の文字列。成功かつdata:のみ格納 |

metadataByUuidはDOM内で重複排除。Workerは別マップで画像と添付を取得するため、同一資源を二重fetchし得る。キー衝突時の自動連番なし（LIM-02）。

## 5. 成功応答のpayload
templateHtml: string、markdown: string、attachments: object、outputFileName: string。
失敗応答はsuccess:falseとerror:stringで、エラーコード・部分失敗一覧は含めない。詳細は32。
