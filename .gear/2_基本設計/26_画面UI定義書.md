# 画面UI定義書

## SCR-001: ボタン挿入
根拠: content.js injectExportButton。

| 項目 | 定義 |
| --- | --- |
| 表示条件 | pathname末尾が小文字.md、ボタン/ラッパー未存在、挿入先が見つかる |
| ボタン | id=ktm-export-btn、表示: 英語「Export to KanTanMarkdown」 / 日本語「かんたんMarkdownへエクスポート」、緑背景・白文字 |
| 挿入先優先順 | raw-button.closest(ButtonGroup)、なければraw-buttonの祖父要素。Rawボタンなしの場合は.Box-header .d-flex→file-action-button-group→.file-header .file-actions |
| Raw系ラッパー | id=ktm-export-wrapper。既存divのclassを模倣、ボタン高さ32px/文字14px/左余白8px |
| 進行状態 | モーダル確定後、英語「Exporting...」 / 日本語「エクスポート中...」、disabled=true。応答/取消/捕捉例外で元表示に戻す |
| 再描画 | 初回init、URL変更時即init、同一URL内DOM更新は500msデバウンス |

非.mdページで新規挿入しないが、既存ボタンを能動的に削除する処理はない。

## SCR-003: モーダル
根拠: content.js showEditionSelector。

| 要素 | 定義 |
| --- | --- |
| 背景 | ktm-modal-overlay、画面全体fixed、黒50%透過、z-index=1000000、中央配置 |
| 本体 | ktm-modal-box、幅350px、padding20px、角丸8px、GitHub CSS変数とfallback色 |
| 見出し | 英語「Select Export Edition」 / 日本語「エクスポートエディションの選択」 |
| 説明 | 英語「Please select the template edition for the output HTML.」 / 日本語「出力するHTMLのテンプレートエディションを選択してください。」 |
| select | ktm-edition-select。lite:Lite (ktm-lite.html)、standard:Standard (ktm-std.html)、full:Full (ktm-full.html) |
| 初期値 | storageのeditionまたはlite。一致しない値ではブラウザのselect初期選択に依存 |
| 確定 | 英語「Export」 / 日本語「エクスポート」。閉じてonSelect(value)、保存はしない |
| 取消 | 英語「Cancel」 / 日本語「キャンセル」、Escape、overlay自身クリック。閉じてonCancel |

closeはoverlayとkeydownを解除。既存overlayを置換する経路は旧keydownを解除しない（LIM-09）。フォーカス移動・トラップ、role=dialog、aria-modal、Enter専用処理は未実装。

## SCR-002: オプション
根拠: options.html、options.js DOMContentLoaded。

| 要素 | 初期値・制御 | イベント |
| --- | --- | --- |
| languageラジオ | en（English、既定）/ ja（日本語） | 変更時に画面全体（リンク、タイトル、ラベル、ボタン、テスト結果、トースト）即時切替 |
| 公式リンク | id=official-repo-link。en「KanTanMarkdown Original Repository (Archived) here」/ ja「かんたんMarkdown オリジナルリポジトリ（アーカイブ）はこちら」 | 外部リンク（target=_blank） |
| repo_typeラジオ | original（オリジナル(tatesuke)）/ fork（フォーク(hiro-gj)、既定）/ custom（その他） | originalまたはfork選択で初期URL反映、URL欄は編集可能・テスト有効。customで入力/テスト有効 |
| custom_repo_url | 初期値 `https://github.com/hiro-gj/KanTanMarkdown`。編集可能 | 保存/テスト時trim、必須検証 |
| editionラジオ | lite既定、standard、full | 保存値の既定edition選択 |
| save-btn | en「Save」/ ja「保存」 | 検証→local.set→toast→1000ms後close |
| test-btn | en「Test Connection」/ ja「接続テスト」、初期有効 | 形式検証→権限→HEAD、test-result更新 |
| cancel-btn | en「Cancel」/ ja「キャンセル」 | window.close、保存しない |
| test-result | 初期空、成功success（緑）、失敗error（赤） | テスト開始で「Testing connection...」 / 「接続テスト中...」 |
| toast | 初期display:none、en「Settings saved successfully」 / ja「設定を保存しました」 | 表示後1500msで非表示（1000msでタブclose予定） |

カスタムURLの受理範囲は `^https://github\.com/[a-zA-Z0-9_-]+/[a-zA-Z0-9_-]+$`。末尾/、.git、ドットを含むrepo、http、クエリ、フラグメントは不受理。前後空白はtrimで許容する。
保存形式エラーはalert（en「Invalid custom repository URL format.」 / ja「カスタムリポジトリURLの形式が正しくありません。」）で中断。

### 接続テスト結果（多言語対応）
| 条件 | 英語表示（en） | 日本語表示（ja） |
| --- | --- | --- |
| URL不正 | Error: Invalid URL format. (e.g. https://github.com/username/repository) | エラー：URLの形式が正しくありません。(形式: https://github.com/ユーザー名/リポジトリ名) |
| 権限拒否 | Connection failed: Host permission was denied. | 接続失敗：拡張機能へのホスト権限の承認が拒否されました。 |
| response.ok | Connection successful: KanTanMarkdown template detected. | 接続成功：かんたんMarkdownテンプレートを検出しました。 |
| HTTP非成功 | Connection test error: Template not found. Please check GitHub Pages publication status. | 接続テストエラー：テンプレートが見つかりません。GitHub Pagesの公開状態を確認してください。 |
| fetch例外 | Connection failed: Network or server error occurred. | 接続失敗：サーバーへの疎通エラーが発生しました。 |

接続テスト中にボタンを無効化しない。入力変更で過去の結果が必ず消えるわけではない。保存は接続テストの成功を要求しない。

## SCR-004: 生成HTML内添付UI
各添付liにデータscript、layerContent、trimInfo、↑、↓、fileName、Insert Tag、Edit、Download、×を挿入する。data:image/でない添付はEditをdisabledにする。各操作の実行処理は外部テンプレートに委譲する。
