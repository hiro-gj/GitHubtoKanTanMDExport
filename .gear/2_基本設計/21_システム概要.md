# システム概要

## 1. 構成と責務
専用サーバー・DBなしのブラウザ拡張。外部通信は存在するため、完全オフラインの変換器ではない。

| コンポーネント | 責務 | 実装 |
| --- | --- | --- |
| Content Script | DOM監視、ボタン/モーダル、Raw URL/添付メタデータ収集、要求送信、HTML合成、ダウンロード | content.js |
| Service Worker | local設定読込、Raw/テンプレート/添付のfetch、Base64化、参照置換、出力名決定、応答 | background.js |
| Options | 設定編集、URL検証、権限確認、HEAD疎通、local保存 | options.html / options.js |
| Chrome local storage | 3つの設定キーの永続化。本文・添付・履歴を保存しない | chrome.storage.local |
| 外部配信 | GitHub Raw、GitHub添付/CDN、GitHub Pagesテンプレート | HTTPS fetch |
| 配布パイプライン | タグ起点でmanifest更新・ZIP・Release作成 | release-extension.yml |

## 2. 起動・実行契機
- manifest_version=3。Service Workerはbackground.js、content scriptはhttps://github.com/*にcontent.js。
- content_scriptsにrun_at、all_frames、typeの指定なし。独自のpopup・actionクリックハンドラなし。
- options_ui.page=options.html、open_in_tab=true。拡張メニュー等から独立タブを開く。
- JavaScript/HTML/CSSと標準Web APIを利用。実行コードにnpm依存・ビルド工程なし。

## 3. データフロー
local設定→モーダルの既定値。実行時選択→exportMarkdown要求。Raw本文→画像解析。GitHubプレビューDOM→添付メタデータ。
Workerは取得したテンプレート・置換済みMarkdown・Data URL辞書・出力名を返す。Content Scriptが文字列置換で単一HTML化し、a.downloadで保存する。chrome.downloadsは使用しない。

## 4. 信頼境界・権限
| 種別 | 宣言内容 |
| --- | --- |
| permissions | storage |
| host_permissions | https://github.com/*、https://*.github.io/*、https://raw.githubusercontent.com/*、https://*.githubusercontent.com/* |
| optional_host_permissions | https://*/* |

Optionsは接続テスト時のみcontains/requestを呼ぶ。Workerはホスト権限の追加要求や送信者・payloadの厳密検証を行わない。外部URL・テンプレートは信頼できる配信先を使う必要がある。
fetchはブラウザの権限・認証・リダイレクト等の制約を受ける。「CORS/認証を無条件に回避」とは扱わない。
