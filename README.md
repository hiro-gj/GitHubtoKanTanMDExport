# GitHubtoKanTanMDExport
GoogleChrome拡張機能「GitHubMarkdown→かんたんMarkdown変換」

## 概要
本拡張機能は、GitHub上に格納されているMarkdownドキュメント（*.md）を、手軽にスライド表示・閲覧・共有できるWebツール「かんたんMarkdown」のフォーマットへシームレスにエクスポートするためのブラウザ拡張機能です。

外部の中継サーバーを一切利用しない「ゼロ・バックエンド」設計となっており、表示中のドキュメントや画像データのフェッチ・変換はすべてブラウザ（ローカルサンドボックス）内で完結するため、プライベートリポジトリであっても高いセキュリティレベルを保ちながらシームレスにエクスポートを実行できます。

## 主な機能
1. **エクスポートボタンの自動インジェクション**:
   - GitHubのMarkdownプレビューページ（*.md）にアクセスすると、RawやBlameボタンの並びに「かんたんMarkdownへエクスポート」ボタンを自動で動的にインジェクションします（GitHubのSPA遷移にも対応）。
2. **添付画像データの自動Base64エンコード**:
   - Markdown内の画像リンクを検出。相対URL画像についてもGitHub上の絶対Raw URLから非同期でフェッチし、Base64（Data URL）形式に変換。かんたんMarkdownの添付ファイルオブジェクトとして埋め込みます。
3. **添付挿入独自タグへの自動置換**:
   - 元の画像構文（`![]()`形式）を、かんたんMarkdownの仕様である添付挿入独自タグ（`[かんたんMarkdown添付ファイル:画像名]`）へ自動で一括置換します。
4. **選べるエディションとカスタムリポジトリ設定**:
   - 設定（オプション）画面から、かんたんMarkdownのエディション（Lite/Standard/Full）を切り替え可能。
   - オリジナルの配信元リポジトリ（tatesuke）に加え、独自にフォーク・カスタマイズされたカスタムリポジトリを指定可能。さらに、そのリポジトリが正しくホスティングされているか疎通確認テスト（接続テスト）を行えます。
5. **自己完結型パッケージ生成機能**:
   - テンプレートHTML、置換後のMarkdown本文、およびBase64化した添付画像データを1ファイルに統合し、`[リポジトリ名]_[元ファイル名].html` のファイル名で自動ダウンロードします。ダウンロードしたHTMLをダブルクリックするだけで、スライドが即座に表示されます。

## 導入手順（インストール方法）

### 開発者モードからの読み込み（ローカル環境）
1. 本リポジトリのソースコードを任意のフォルダにクローンまたはダウンロード（ZIP）して解凍します。
2. Google Chromeブラウザを開き、アドレスバーに `chrome://extensions/` を入力して開きます。
3. 画面右上にある **「デベロッパー モード」** のトグルスイッチをONにします。
4. 画面左上に出現する **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
5. 解凍したフォルダ（`manifest.json` が配置されているフォルダ）を選択して読み込みます。

## 使い方

### 1. 初期設定（オプション画面）
1. インストール後、Chromeのツールバーにあるパズルマーク（拡張機能ボタン）から、本拡張機能を見つけて右クリックし **「オプション」** を選択します。
2. 基準とする **「かんたんMarkdownリポジトリ選択」** で、オリジナル（tatesuke）または、フォークされたカスタムリポジトリ（「その他」を選択してURLを入力）を指定します。
3. **「エディション選択」**（Lite / Standard / Full）からベースとしたいテンプレートを選択し、**「保存」** をクリックします。

### 2. エクスポートの実行
1. GitHub上で、エクスポートしたいMarkdownファイル（例：`README.md`）のプレビューページを開きます。
2. ファイル右上にある **「かんたんMarkdownへエクスポート」** ボタンをクリックします。
3. バックグラウンドで画像等のフェッチ＆Base64変換が自動実行され、数秒後にスライドショーが埋め込まれた自己完結型のHTMLファイルがダウンロードされます。
4. ダウンロードされたHTMLファイルをブラウザで開くことで、即座にスライドとしてプレビュー可能です！
